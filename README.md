SafiShop — E-commerce Full-stack Application

​A modular e-commerce solution designed for small-to-medium businesses. The project features a robust backend architecture and a functional frontend for testing core business logic.
​
🚀 Technologies Used
​
Backend
​
Framework: ASP.NET Core 10.0 (Web API)
​
Database: PostgreSQL
​
ORM: Entity Framework Core (Code First approach)
​
Documentation: Swagger UI (OpenAPI)
​Containerization: Docker & Docker Compose
​
Frontend
​
Library: React.js
​
Language: TypeScript
​
State Management: Hooks & Context API
​
🛠 Key Features
​
Product Management: Full CRUD operations for managing inventory.
​
Telegram Integration: Automated notifications for new orders (via Telegram Bot API).
​
Database Migrations: Version-controlled schema updates using EF Core.
​
Scalable Architecture: Clean separation of concerns between API, Business Logic, and Data layers.
​
📦 Getting Started
​
Prerequisites
​
Docker Desktop
​
.NET SDK 10.0 (for local development)
​
Running with Docker
​
The easiest way to launch the entire stack (API + Database + Frontend) is using Docker Compose:

docker-compose up --build

Once the containers are running:
​Backend API: http://localhost:5075
​Swagger UI: http://localhost:5075/swagger
​Frontend: http://localhost:5173
